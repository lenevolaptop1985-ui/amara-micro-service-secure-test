Google Drive Backup & Recovery
The app never asks for or stores your Gmail password. Google OAuth grants the app the limited drive.file Drive scope needed for its own backup files.
Important: direct Google OAuth requires the HTML app to run from a secure HTTPS web origin. If you open the file directly as file://, host this app on your HTTPS domain.
When set, the database sent to Google Drive is AES-GCM encrypted in the browser. Keep this PIN safe; without it, an encrypted cloud backup cannot be restored. The PIN is kept only in this open app session and is not saved to browser storage. Reset PIN clears it from the current session — do this if you're changing the PIN or using a shared device. If the box is ever empty during a sync, this app will now warn you instead of silently uploading an unencrypted backup.
